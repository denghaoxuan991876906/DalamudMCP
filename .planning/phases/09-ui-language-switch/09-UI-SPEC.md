# Phase 9 — UI Design Contract

> Visual and interaction contract for Phase 9: 可切换界面语言 (Switchable UI Language).
> Context: This is a Dalamud FFXIV plugin using **ImGui** (immediate-mode GUI), not web/CSS.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

| Property | Value |

| Icon library | N/A — ImGui text-only; no icon system used |

## Spacing Scale

N/A — ImGui spacing is specified as inline pixel values in code (e.g., `ImGui.SetNextItemWidth(120f)`), not via CSS tokens. The project does not define or use a spacing token system.

N/A — ImGui renders all text via the game client's font pipeline. Font size, weight, and line height are controlled by Dalamud/ImGui internal settings, not by the plugin. All text in the config window uses the default ImGui text renderer (`ImGui.Text`, `ImGui.TextWrapped`, `ImGui.TextColored`).

## Layout Structure

The Phase 9 change affects exactly **one new UI element** placed within the existing config window. No new windows, panels, or tabs are created.

### Existing Window Structure (unchanged)

```
PluginConfigWindow (ImGui.Begin)
├── DrawHeader()          ← Language selector added here
│   ├── Title + subtitle
│   ├── Inline badges (pipe, HTTP, exposure)
│   └── Separator
├── DrawOverview()
│   ├── DrawRuntimePanel()
│   └── DrawServerPanel()
├── DrawQuickStart()
├── DrawAdvancedDetails()
└── DrawOperations()
```

### Language Selector — Placement

Inserted at the end of `DrawHeader()`, **after** the inline badges and **before** the separator line. This places it at the top-right area of the header, visually accessible without scrolling.

```
DrawHeader()
  ├── "DalamudMCP" title (AccentColor)
  ├── Subtitle text
  ├── [管道在线/离线] [HTTP 在线/已停] [N/M 已暴露]    ← inline badges
  ├── [中文 / English]  ← NEW: language combo box, right-aligned
  ├── Hint text line
  ├── Separator
```

### Language Selector — Specification

| Property | Value |
|----------|-------|
| ImGui widget | `ImGui.Combo("##lang", ...)` |
| Item width | `ImGui.SetNextItemWidth(120f)` |
| Options | `["中文", "English"]` — exactly 2 items, labeled in their own language |
| Language values | `"zh"`, `"en"` (mapped 1:1 to index) |
| Default selection | `"zh"` (index 0) — Chinese |
| Internal label | `"##lang"` (hidden label, no visible text prefix) |
| Position | Header area, placed via `ImGui.SameLine()` after the badge row, or on its own line before the hint text. Exact positioning determined during implementation for visual balance. |

**Placement code pattern:**

```csharp

// After the last badge, SameLine + SameLine spacing to right edge
// Option B: Separate line before separator (fallback if Option A overflows)
```

## Interaction Contract

### Language Switch Behavior

| Trigger | User selects a different language from the combo box |
|---------|------------------------------------------------------|
| Response | Immediate — no confirmation dialog, no restart required |
| Visual feedback | No loading spinner; text changes on next ImGui frame draw |
| Animation | None — ImGui immediate mode redraws on the next frame |

### State Transition

```
User selects "English"
  → ImGui.Combo returns new index
  → string langCode = languages[selectedIndex]  // "en"
  → configurationStore.Update(c => c.SelectedLanguage = langCode)
  → localization.SetLanguage(langCode)
  → localization dispatches LanguageChanged event
  → PluginConfigWindow sets languageSwitchPending = true
  → RefreshModel(force: true) recalculates all model strings
  → Next ImGui.Draw() re-renders all text with new language
```

### Refresh Scope

On language switch, the following must update without plugin restart:

| UI Region | Update Mechanism | Risk of Stale Text |
|-----------|-----------------|--------------------|
| Header title + subtitle | `ImGui.Text(loc["..."])` — draw-time lookup | Low (no caching) |
| Badge texts | `ImGui.Text(loc["..."])` — draw-time lookup | Low |
| Panel titles + subtitles | `ImGui.Text(loc["..."])` — draw-time lookup | Low |
| Status labels (`DrawKeyValue`, `DrawStatusLine`) | `ImGui.TextColored(MutedColor, loc["..."])` — draw-time lookup | Low |
| Status value texts | Model property getters return `loc["key"]` (non-caching) | Low (computed per-frame) |
| Checkbox labels | `ImGui.Checkbox(loc["..."], ...)` — draw-time lookup | Low |
| Button labels | `ImGui.Button(loc["..."], ...)` — draw-time lookup | Low |
| Table headers | `ImGui.TableSetupColumn(loc["..."], ...)` — draw-time lookup | Low |
| Table cell tags | `ImGui.Text(loc["..."])` — draw-time lookup | Low |
| Operation CLI/MCP prefixes ("CLI: ", "MCP: ") | `loc["label.cli_prefix"]` at draw time in `DrawOperations()` | Medium — currently cached in `PluginConfigOperationRow.CliCommandText` |
| Operation summaries | `loc[$"op.{operationId}.summary"] ?? operation.Summary` | Low |
| Empty state text | `ImGui.TextColored(MutedColor, loc["..."])` | Low |
| Reader status text | Model property returns computed string via `loc[...]` | Low (non-caching) |
| Exposure status text | Model property returns computed string via `loc[...]` | Low (non-caching) |

**Critical implementation note:** `PluginConfigOperationRow.CliCommandText` and `PluginConfigOperationRow.McpToolText` are currently set once in the constructor and never updated. After Phase 9, these must become draw-time computed values (via `loc["label.cli_prefix"] + CliCommand`), not cached constructor strings.

### Persistence

| Property | Storage | Value Type | Default | Version |
|----------|---------|------------|---------|---------|
| `SelectedLanguage` | `PluginUiConfiguration` / `SavePluginConfig()` | `string` | `"zh"` | Config Version 4 |

**Migration:** Increment `PluginUiConfiguration.Version` from `3` to `4`. New property `SelectedLanguage` defaults to `"zh"` (no migration logic needed for existing configs — the default setter handles pre-migration loads).

### Startup Behavior

```
PluginEntryPoint.OnLoad
  → configurationStore.Current (loaded from disk)
  → if SelectedLanguage is not null/empty:
      → localization.SetLanguage(configurationStore.Current.SelectedLanguage)
  → else:
      → localization.SetLanguage("zh")  // default
```

### Operation Attributes (external to window/model)

Operation descriptions in `[Operation(Description = "...")]` and `[Option(Description = "...")]` attributes remain in English as compile-time constants. They serve as:
1. The **fallback** in the config window when no localized override exists
2. The **canonical source** for the CLI binary (which cannot access the localization service)

To localize operation summaries in the config window table, add lookup keys in the localization JSON:

```
op.{operationId}.summary  → localized summary text for config window display
op.{operationId}.description  → localized description text
```

Display logic: `loc.GetString($"op.{operation.OperationId}.summary") ?? operation.Summary`
