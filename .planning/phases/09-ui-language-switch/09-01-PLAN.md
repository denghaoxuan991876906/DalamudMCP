  <action>
    创建两个文件：

    1. `src/DalamudMCP.Plugin/Ui/Localization/IUiLocalization.cs`

    命名空间: `DalamudMCP.Plugin.Ui.Localization`

    接口定义:
    ```csharp
    public interface IUiLocalization
    {
        string this[string key] { get; }
        string GetString(string key);
        string CurrentLanguage { get; }
        void SetLanguage(string language);
        event Action? LanguageChanged;
    }
    ```

    2. `src/DalamudMCP.Plugin/Ui/Localization/JsonLocalization.cs`

    命名空间: `DalamudMCP.Plugin.Ui.Localization`

    - sealed class，实现 IUiLocalization, IDisposable
    - 构造函数中调用 LoadFromResource 加载 en 和 zh 词典
    - `currentLanguage` 字段，默认 `"zh"`
    - `this[string key]` 委托给 `GetString(key)` 以保持单一入口点的一致性
    - `GetString` 实现:
      - `currentLanguage == "zh"` 时: 优先返回 zh.TryGetValue 结果，缺失时返回 en.GetValueOrDefault(key, key)
      - 其他语言时: 返回 en.GetValueOrDefault(key, key)
      - 注意: 当 key 在 JSON 中都不存在时，回退为返回 key 本身（方便调试时识别缺失键）
    - `SetLanguage`: 如果 `currentLanguage == language` 则直接 return；否则更新 `currentLanguage` 并触发 `LanguageChanged?.Invoke()`
    - 为安全起见，`SetLanguage` 只接受 `"zh"` 或 `"en"`，其他值忽略（静默拒绝）
    - `LoadFromResource` 是 private static 方法:
      ```csharp
      private static Dictionary<string, string> LoadFromResource(string resourceName)
      {
          var assembly = typeof(JsonLocalization).Assembly;
          using var stream = assembly.GetManifestResourceStream(resourceName)
              ?? throw new InvalidOperationException($"Missing embedded resource: {resourceName}");
          return JsonSerializer.Deserialize<Dictionary<string, string>>(stream)
              ?? new Dictionary<string, string>();
      }
      ```
    - `Dispose` 方法体为空（为将来可能的资源清理预留）
    - 需要 using: `System.Text.Json`, `System.Text.Json.Serialization` 用于反序列化（如果使用了 JsonSerializerOptions）

    资源名称规则（必须在代码和 csproj 中一致）:
    - `DalamudMCP.Plugin.lang.en.json`
    - `DalamudMCP.Plugin.lang.zh.json`
  </action>
