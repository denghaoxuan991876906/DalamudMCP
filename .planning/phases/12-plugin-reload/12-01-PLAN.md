**6. CreateDalamudExecutor 静态方法：**
- 接收 `IDalamudPluginInterface pluginInterface, IFramework framework`
- 返回异步委托，执行逻辑：
  a. 验证 `request.PluginName` 非空（抛 ArgumentException）
  b. 检查是否自身重载：`string.Equals(request.PluginName.Trim(), pluginInterface.InternalName, StringComparison.OrdinalIgnoreCase)` → 返回 `self_reload_blocked`
  c. 查找目标插件：`pluginInterface.InstalledPlugins.FirstOrDefault(p => string.Equals(p.InternalName, request.PluginName.Trim(), StringComparison.OrdinalIgnoreCase))`
  d. 未找到 → 返回 `plugin_not_found`
  e. 检测是否在 Framework 线程：如果 `framework.IsInFrameworkUpdateThread`，直接调用 Reload()；否则通过 `framework.RunOnFrameworkThread(() => { plugin.Reload(); })` 编排
  f. Reload() 成功 → 返回 `reload_initiated`
  g. Reload() 抛出异常 → 捕获并返回 `reload_failed` + 异常消息
