<objective>
Validasi runtime: Plugin dapat dimuat tanpa error di Dalamud API 15, dan semua 20+ operasi berfungsi dengan benar.
</objective>

<tasks>

<task type="human-action" tdd="false">
  <name>Task 1: Verifikasi pemuatan plugin di API 15 runtime</name>
  <action>
    1. Buka FFXIV dengan XIVLauncher (pastikan menggunakan Hooks/dev branch API 15)
    2. Buka Dalamud Plugin Installer → tab "Installed Plugins"
    3. Cari "DalamudMCP" — pastikan statusnya "Loaded"
    4. Buka Dalamud Console (biasanya /xllog) dan periksa tidak ada error terkait DalamudMCP
    5. Perhatikan khususnya:
       - Tidak ada MissingMethodException
       - Tidak ada TypeLoadException
       - Tidak ada error terkait API level mismatch
       - Plugin menunjukkan `DalamudApiLevel: 15`
  </action>
  <acceptance_criteria>
    - Plugin muncul sebagai "Loaded" di daftar plugin
    - Tidak ada error di Dalamud console saat plugin dimuat
    - Plugin info menunjukkan API Level 15
  </acceptance_criteria>
</task>

<task type="human-action" tdd="false">
  <name>Task 2: Verifikasi operasi game berfungsi (observasi)</name>
  <action>
    Uji operasi observasi (read-only) berikut satu per satu melalui CLI atau MCP client:
    1. `get_player_info` — informasi pemain dasar
    2. `get_inventory` — data inventory
    3. `get_available_quests` — daftar quest tersedia
    4. `get_current_quest_objective` — objective saat ini
    5. `get_addon_info` — informasi addon UI
    6. `get_addon_callback_values` — nilai callback addon
    7. Operasi observasi lainnya yang tersedia
    
    Untuk setiap operasi:
    - Kirim request dan periksa response tidak error
    - Verifikasi data yang dikembalikan masuk akal (tidak null/kosong jika seharusnya ada data)
  </action>
  <acceptance_criteria>
    - Setiap operasi observasi mengembalikan response valid tanpa error
    - Data yang dikembalikan sesuai dengan state game aktual
  </acceptance_criteria>
</task>

<task type="human-action" tdd="false">
  <name>Task 3: Verifikasi operasi aksi berfungsi</name>
  <action>
    Uji operasi aksi (write) berikut dengan hati-hati:
    1. `addon_input` — kirim input ke addon (uji di addon sederhana seperti Inventory)
    2. `addon_event` — kirim event ke addon
    3. Operasi aksi lainnya yang tersedia
    
    PERHATIAN: Operasi aksi mengubah state game. Uji di area aman, jangan di raid/dungeon.
    
    Untuk setiap operasi:
    - Verifikasi aksi berhasil dieksekusi (response menunjukkan sukses)
    - Verifikasi efek aksi terlihat di game
  </action>
  <acceptance_criteria>
    - Setiap operasi aksi berhasil dieksekusi tanpa error
    - Efek aksi terlihat di game (misalnya input terkirim ke addon)
  </acceptance_criteria>
</task>

<task type="human-action" tdd="false">
  <name>Task 4: Verifikasi operasi unsafe (AddonInput, InteractWithTarget)</name>
  <action>
    Khusus untuk operasi yang menggunakan unsafe code / FFXIVClientStructs:
    1. `interact_with_target` — interaksi dengan target
    2. `addon_input` dengan berbagai AddonInputType (Keyboard, Mouse, Gamepad)
    
    Ini adalah area berisiko tinggi karena Patch 7.5 mungkin mengubah memory layout.
    Uji dengan berbagai tipe input dan verifikasi tidak crash.
  </action>
  <acceptance_criteria>
    - Operasi unsafe berjalan tanpa crash atau error
    - Tidak ada perubahan perilaku dibandingkan API 14
  </acceptance_criteria>
</task>

</tasks>

<verification>
Semua task di atas memerlukan verifikasi manual dalam game. Tidak ada automated tests untuk fase ini.
</verification>
